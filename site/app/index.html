        Extension Le Bon Coin

        L'extension RetroRevente pour Safari, Chrome et Firefox remplit tout seul chaque étape du dépôt d'annonce sur Le Bon Coin (titre, description, état, prix, photo) et propose des réponses types aux acheteurs. Tu relis et tu publies toi-même.

        Sur Safari, l'extension doit d'abord être autorisée sur ce site : clique sur l'icône RetroRevente de la barre d'outils, choisis « Toujours autoriser sur ce site web », recharge la page puis clique à nouveau sur « Connecter l'extension ». (Ou : Safari → Réglages → Extensions → RetroRevente → Modifier les sites web… → retrorevente.fr : Autoriser.)
